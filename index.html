DataMaps Marker Editor

Paste a map's JSON, drag markers into place, then copy the JSON back into the wiki. The background picture and marker icons load from the wiki by their file names; use the buttons only for pictures that aren't on the wiki yet. Nothing is uploaded.

Groups

Pick the group that “Add marker” places into. The eye hides or shows a group on the map (only here; nothing changes in the JSON). Shift+click an eye to show only that group.

Markers

Selected marker

Click a marker on the map or in the list. Arrow keys nudge it by 0.1 (Shift: 1).

Areas

Shaded shapes, e.g. where a mob can spawn. “+ Draw area” in the toolbar, or “Turn into area” on a marker.

Each one links to NPC:its name; add “| page” after a name to link another page.

Its name shows on the map as a label (clickable too); drag the label to place it. For a link out at the edge, a name like “The Ruins of Harbourview →” works well. With a colour the shape is lightly tinted; without one it only shows when hovered.

Drag a corner to move it, drag the shape to move it all, click a + to add a corner, Shift+click a corner to remove it.
